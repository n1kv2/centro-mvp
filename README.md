# CEnTRO · MVP prototipo

Prototipo grafico dell'MVP CEnTRO: tutte le schermate e i flussi del mockup, con interazioni simulate in locale (nessun backend).

**Provalo dal telefono:** https://n1kv2.github.io/centro-mvp/
Su iPhone: Condividi → «Aggiungi alla schermata Home» per usarlo a tutto schermo.

- I dati restano solo nel browser di chi lo prova (localStorage).
- La mappa per saltare tra le schermate compare solo aggiungendo `?demo=1` all'indirizzo.

Dettagli su struttura e tappe in [LEGGIMI.md](LEGGIMI.md).
